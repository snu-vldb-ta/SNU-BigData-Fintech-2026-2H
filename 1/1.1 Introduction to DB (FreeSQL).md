### Section 1.5.2

- 실행 계획은 `explain plan for` 문장과 바로 아래 `select` 문장을 함께 실행해야 나옵니다. (Run Script, F5)

```sql
-- In Oracle FreeSQL, you can check execution plan in the following way ------------- 
-- Full Scan
explain plan for
select * from emp e where deptno = 10;

select *
from table(dbms_xplan.display(format => 'typical'));

-- Create Index
drop index if exists emp_deptno;
create index emp_deptno on emp (deptno);

-- Index Scan
explain plan for
select * from emp e where deptno = 10;

select *
from table(dbms_xplan.display(format => 'typical'));

-- Create external view
create or replace view dept_sal as select deptno, avg(sal) avg_sal from emp group by deptno;
select * from dept_sal;
```

### Section 1.5.3

> ⚠️ **주의사항**: 이 절은 emp 테이블의 이름을 잠시 바꿨다가 되돌립니다.  
> 중간에 멈추면 emp 테이블이 없는 상태로 남아 이후 실습이 실행되지 않습니다. 마지막 두 문장까지 반드시 실행하세요.

```sql
-- CHANGE in logical or conceptual schema
alter table emp rename to emp2;

-- what happens for the next query? (에러가 나는 것이 정상입니다)
select * from dept_sal;

-- redefine the external schema
create or replace view dept_sal as select deptno, avg(sal) avg_sal from emp2 group by deptno;

-- then, what happens for the next query?
select * from dept_sal;

alter table emp2 rename to emp;
drop view dept_sal;
```

### Section 1.7

```sql
drop table if exists account;
create table account (id number, balance number, primary key(id));

insert into account values (1, 100);
insert into account values (2, 200);
commit;

-- An example of "money transfer" transfer
-- TX1: Move 10$ from account 1 to account 2
-- BEGIN transaction; (implicit in SQL*Plus)
update account set balance = balance - 10 where id = 1;
update account set balance = balance + 10 where id = 2;
COMMIT;
```
